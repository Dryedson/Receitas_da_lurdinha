🚀 COMO COMEÇAR
================================================================================

1. RODAR LOCALMENTE
   cd receitas-monetizadas
   npm install
   npm run dev
   
   Abra: http://localhost:3000

2. FAZER DEPLOY
   Opção A (Recomendado):
   - Push para GitHub
   - Conectar ao Vercel
   - Deploy automático
   
   Opção B:
   - Instalar Vercel CLI
   - Executar: vercel deploy

3. CONFIGURAR GOOGLE ADSENSE
   - Obter ID do AdSense
   - Adicionar em app/layout.tsx
   - Fazer deploy
   - Aguardar aprovação (24-48h)
